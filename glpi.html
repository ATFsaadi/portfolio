1. Introduction

GLPI (Gestionnaire Libre de Parc Informatique) est un logiciel libre permettant de :

  • gérer un parc informatique,
  • centraliser les incidents via un système de tickets,
  • gérer les contrats, licences et budgets,
  • collaborer entre utilisateurs et administrateurs IT.

Dans ce tutoriel, nous allons installer GLPI sur une VM Linux avec LAMP, puis configurer un scénario simple : un utilisateur crée un ticket et un administrateur le traite.

[Capture d’écran : logo officiel GLPI ou site web GLPI]

2. Prérequis

  • VM Linux : Ubuntu 22.04 LTS recommandé
  • Ressources minimales : 2 CPU, 4 Go RAM, 20 Go disque
  • Logiciels nécessaires : Apache2, PHP ≥ 7.4 (recommandé 8.2), MariaDB/MySQL ≥ 10.2
  • Extensions PHP : xml, json, mysql, mbstring, curl, gd, intl, zip, bz2, imap, apcu, ldap (optionnel)
[Capture d’écran : version de la VM via lsb_release -a]

3. Préparation du serveur

sudo apt-get update && sudo apt-get upgrade -y
: terminal après mise à jour]

4. Installation du socle LAMP

sudo apt-get install apache2 php mariadb-server -y

sudo apt-get install php-xml php-common php-json php-mysql php-mbstring php-curl php-gd php-intl php-zip php-bz2 php-imap php-apcu -y
sudo apt-get install php-ldap -y
[Capture d’écran : statut Apache systemctl status apache2]

5. Configuration de MariaDB/MySQL

sudo mysql_secure_installation

CREATE DATABASE db23_glpi;
GRANT ALL PRIVILEGES ON db23_glpi.* TO 'glpi_adm'@'localhost' IDENTIFIED BY 'MotDePasseRobuste';
FLUSH PRIVILEGES;
EXIT;
[Capture d’écran : console MySQL après création de la base]

6. Téléchargement et installation de GLPI

cd /tmp
wget https://github.com/glpi-project/glpi/releases/download/10.0.10/glpi-10.0.10.tgz
sudo tar -xzvf glpi-10.0.10.tgz -C /var/www/
sudo chown -R www-data:www-data /var/www/glpi

sudo mkdir /etc/glpi /var/lib/glpi /var/log/glpi
sudo mv /var/www/glpi/config /etc/glpi
sudo mv /var/www/glpi/files /var/lib/glpi
[Capture d’écran : contenu du dossier /var/www/]

7. Configuration Apache et PHP

sudo apt-get install php8.2-fpm -y
sudo a2enmod proxy_fcgi setenvif
sudo a2enconf php8.2-fpm
sudo systemctl reload apache2

echo "session.cookie_httponly = on" | sudo tee -a /etc/php/8.2/fpm/php.ini
sudo systemctl restart php8.2-fpm.service
sudo systemctl restart apache2
[Capture d’écran : test PHP via php -v]

11. Gestion des tickets (cas pratique)

Scénario :

  1. UserTest crée un ticket (ex. : problème d’imprimante)
  2. AdminSupport reçoit le ticket et l’assigne à un technicien
  3. Le ticket est résolu et clôturé
[Captures d’écran : création, suivi et clôture d’un ticket]

12. Bonnes pratiques de configuration

  • Installer SSL avec Let’s Encrypt
  • Mettre à jour régulièrement GLPI et PHP
  • Sauvegarder la base et les fichiers
  • Sécuriser MariaDB et Apache
  • Explorer les plugins (FusionInventory, LDAP, etc.)

13. Conclusion

Nous avons installé et configuré GLPI sur une VM Linux avec LAMP. Un utilisateur peut ouvrir un ticket et un administrateur peut le gérer. L’outil peut être enrichi via des plugins et connecté à un LDAP/Active Directory.
